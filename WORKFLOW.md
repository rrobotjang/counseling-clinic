## 🔄 학습 루프 (Training Loop)

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           🎓 학습 과정                                  │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │                    에피소드 시작 (Episode Start)                 │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                              │                                          │
│                              ▼                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │              환경 초기화 (Environment Reset)                    │   │
│  │  - 모든 에이전트 상태 리셋                                       │   │
│  │  - 관계 행렬 초기화                                              │   │
│  │  - 시간 초기화                                                   │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                              │                                          │
│                              ▼                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │                   스텝 반복 (Step Loop)                         │   │
│  │                                                                 │   │
│  │   ┌─────────────────────────────────────────────────────────┐   │   │
│  │   │  1. 에이전트 선택 (랜덤)                                │   │   │
│  │   │     → agent = random.choice(agents)                     │   │   │
│  │   └─────────────────────────────────────────────────────────┘   │   │
│  │                              │                                  │   │
│  │                              ▼                                  │   │
│  │   ┌─────────────────────────────────────────────────────────┐   │   │
│  │   │  2. 상태 벡터 생성                                      │   │   │
│  │   │     → state = [감정, 에너지, 관계수, ...]               │   │   │
│  │   └─────────────────────────────────────────────────────────┘   │   │
│  │                              │                                  │   │
│  │                              ▼                                  │   │
│  │   ┌─────────────────────────────────────────────────────────┐   │   │
│  │   │  3. 정책 네트워크 → 행동 선택                            │   │   │
│  │   │     → action_idx = policy.get_action(state)             │   │   │
│  │   │     → action_text = templates[action_idx]               │   │   │
│  │   └─────────────────────────────────────────────────────────┘   │   │
│  │                              │                                  │   │
│  │                              ▼                                  │   │
│  │   ┌─────────────────────────────────────────────────────────┐   │   │
│  │   │  4. 환경 스텝 실행                                      │   │   │
│  │   │     → obs, reward, done, info = env.step(action)        │   │   │
│  │   └─────────────────────────────────────────────────────────┘   │   │
│  │                              │                                  │   │
│  │                              ▼                                  │   │
│  │   ┌─────────────────────────────────────────────────────────┐   │   │
│  │   │  5. 보상 수신 및 저장                                   │   │   │
│  │   │     → agent.receive_reward(reward)                      │   │   │
│  │   └─────────────────────────────────────────────────────────┘   │   │
│  │                              │                                  │   │
│  │                              ▼                                  │   │
│  │   ┌─────────────────────────────────────────────────────────┐   │   │
│  │   │  6. 다음 상태?                                          │   │   │
│  │   │     → done? → 다음 에피소드로                            │   │   │
│  │   │     → 아니면 → 스텝 1로 돌아감                          │   │   │
│  │   └─────────────────────────────────────────────────────────┘   │   │
│  │                                                                 │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                              │                                          │
│                              ▼                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │                  에피소드 종료 (Episode End)                    │   │
│  │                                                                 │   │
│  │   ┌─────────────────────────────────────────────────────────┐   │   │
│  │   │  7. 에이전트 학습                                       │   │   │
│  │   │     → agent.learn()                                     │   │   │
│  │   │     → REINFORCE 정책 그래디언트 업데이트                 │   │   │
│  │   └─────────────────────────────────────────────────────────┘   │   │
│  │                                                                 │   │
│  │   ┌─────────────────────────────────────────────────────────┐   │   │
│  │   │  8. 결과 기록                                           │   │   │
│  │   │     → episode_rewards.append(result)                    │   │   │
│  │   └─────────────────────────────────────────────────────────┘   │   │
│  │                                                                 │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                              │                                          │
│                              ▼                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │                 다음 에피소드 또는 평가                          │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    🤖 에이전트 의사결정 흐름                            │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ┌──────────────┐                                                       │
│  │   상태 입력   │                                                       │

│  │   감정 원-핫 (8차원)  ─┐                                         │   │
│  │   에너지 (1차원)       ─┼→  state = [10차원 벡터]                │   │

│         ▼                                                               │

│  │     "안녕!", "반가워!", "어떻게 지냈어?", "같이 산책할까?"   │   │
│  │   ]                                                             │   │
│  │   action_text = templates[action_idx]                            │   │
│  └──────────────────────────────────────────────────────────────────┘   │
│         │                                                               │
│         ▼                                                               │
│  ┌──────────────┐                                                       │
│  │   행동 출력   │                                                       │
│  └──────────────┘                                                       │
│                                                                         │

```

## 📈 학습 알고리즘 (REINFORCE)

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    📈 REINFORCE 정책 그래디언트                         │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  1. 에피소드 수집                                                        │
│     ┌─────────────────────────────────────────────────────────────┐    │
│     │ trajectory = [(s₁, a₁, r₁), (s₂, a₂, r₂), ..., (sₜ, aₜ, rₜ)] │
│     └─────────────────────────────────────────────────────────────┘    │
│                              │                                          │
│                              ▼                                          │
│  2. 보상 계산 (Discounted Returns)                                     │
│     ┌─────────────────────────────────────────────────────────────┐    │
│     │ Gₜ = rₜ + γ·rₜ₊₁ + γ²·rₜ₊₂ + ...                         │    │
│     │                                                            │    │
│     │ returns = [G₁, G₂, ..., Gₜ]                               │    │
│     └─────────────────────────────────────────────────────────────┘    │
│                              │                                          │
│                              ▼                                          │
│  3. 정규화                                                              │
│     ┌─────────────────────────────────────────────────────────────┐    │
│     │ returns = (returns - mean) / (std + ε)                      │    │
│     └─────────────────────────────────────────────────────────────┘    │
│                              │                                          │
│                              ▼                                          │
│  4. 정책 그래디언트 계산                                                │
│     ┌─────────────────────────────────────────────────────────────┐    │
│     │                                                            │    │
│     │ policy_loss = -Σ log_π(aₜ|sₜ) · (Gₜ - V(sₜ))             │    │
│     │                                                            │    │
│     │ value_loss = Σ (V(sₜ) - Gₜ)²                              │    │
│     │                                                            │    │
│     │ loss = policy_loss + 0.5 · value_loss                      │    │
│     └─────────────────────────────────────────────────────────────┘    │
│                              │                                          │
│                              ▼                                          │
│  5. 가중치 업데이트                                                     │
│     ┌─────────────────────────────────────────────────────────────┐    │
│     │ optimizer.zero_grad()                                       │    │
│     │ loss.backward()                                             │    │
│     │ optimizer.step()                                            │    │
│     └─────────────────────────────────────────────────────────────┘    │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 🎯 학습 파라미터

| 파라미터 | 기본값 | 설명 |
|---------|-------|------|
| `num_episodes` | 100 | 학습 에피소드 수 |
| `steps_per_episode` | 50 | 에피소드당 스텝 수 |
| `learning_rate` | 0.001 | 학습률 |
| `gamma` | 0.99 | 할인 인자 |
| `state_dim` | 10 | 상태 벡터 차원 |
| `num_actions` | 21 | 행동 공간 크기 |
| `hidden_dim` | 64 | 은닉층 차원 |

## 📊 기대 효과

1. **초기 (에피소드 0-10)**: 랜덤 행동, 낮은 보상
2. **중기 (에피소드 10-50)**: 행동 패턴 형성, 보상 증가
3. **후기 (에피소드 50+)**: 최적 전략 학습, 안정적 보상
